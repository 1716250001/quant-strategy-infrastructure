## B2 单策略回测（PoC-2 任务 2.8，2026-09-26）

- **实测 12.99s**（门槛 15s ✅，余量 13%；三次复测区间 12.7-13.4s）：沪深300 前 20 权重等权、月首交易日决策（PIT 月末成分快照）、次日开盘执行，2016-01-01..2025-12-31
- 规模：2430 交易日 | 2165 订单 | 2136 成交 | 29 拒单 | 11620 事件（全量落盘 JSONL）
- 环境：Windows / Python 3.13 / TushareParquetFeed 直读；收口态 `bt check` 5/5（ruff 0 违规 / 六架构契约 KEPT）

### 优化留痕（17.48s → 12.71s，四刀均先 profile 后动刀）

| # | 热点（证据） | 刀法 | 收益 |
|---|---|---|---|
| 1 | 市场事件摘要落盘 4000 symbol JSON 数组 ×2/日 | 摘要计数化（`n_symbols`） | ≈7s → <0.1s |
| 2 | `on_open` 每日无条件物化 states（B2 策略不查状态） | ctx states 惰性装载（`LazyStates`，构造时固化 date/标的集合） | ≈2.3s 豁免 |
| 3 | `n_symbols` 取数触发 4000 元素列切片 ×2/日 | `_LazyCrossSection.__len__` 快速路径（行区间宽） | ≈0.1s |
| 4 | `_limits` 全年表构建 70-175 万行/年 ≈6.4s（cProfile tottime 6.02s/396 次调用，最大热点） | `(year, wanted)` 子集过滤 + frozenset 结果缓存（`pc.is_in` 列过滤，仅物化 ≤40 标的×250 行） | 6.4s → ≈2s |

不变式：全程 `_LazyCrossSection` bisect 单行构造（B1 物化段 22s 禁区未触发）；双跑 diff=0 保持。

### PoC-3 后复测（2026-09-26，公司行动接入引擎后）

- **实测 13.62s < 15s ✅**（余量 9%）：同场景复跑，步骤①新增 dividend 全表装载（`read_full` ≈0.5s，跨年归档正确性优先——见 feed.corporate_actions docstring）+ CA 事件流
