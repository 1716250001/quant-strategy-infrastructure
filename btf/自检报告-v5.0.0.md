## 五、复现本报告的方式

```bash
cd <btf 仓根>
PY=<你的 venv>/Scripts/python.exe

$PY -m btf.cli.main --version
$PY -m btf.cli.main check
$PY -m btf.cli.main config-check examples/config_rotation.yaml
$PY tools/schema_guard.py
$PY -m pytest --collect-only -q -o addopts="--strict-markers"
$PY -m pytest tests/test_smoke.py -q -k drive
$PY -m pytest -q --basetemp "D:/…/_scratch/pytest_tmp/manual-<时间戳>"
$PY -m ruff check .
```

> ⚠ 全量测试**必须**带 `--basetemp` 指到项目内路径，且**独占跑**；否则会出现「用例全过但 exit≠0」与 L5 基准假红。
