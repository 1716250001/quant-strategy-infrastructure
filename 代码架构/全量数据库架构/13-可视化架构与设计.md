# 13 · 可视化架构与设计（第 19 章）

> 一句话：可视化的对象**不是行情**（行情由消费侧画），而是**库自身的状态**——它今天更新了什么、缺什么、多大、可信不可信。
> 事实锚点：2026-09-30（`main.py db-report` 报告生成、`db-schema --json` 结构导出、`freshness`/`db-audit` 结论输出）。
> 与 05 §20.7（机读字典）、09 §14.2（体检判据）、15 §28（可观测性）配套。

---

## 19.1 可视化架构（三层解耦）

```
① 真源层      config.py 规格 · 磁盘 Parquet Footer · 断点 JSON · 日志
                     │  只读
② 视图数据层   db-schema --json  ·  db-audit --json  ·  freshness --json
                ckpt --show --json ·  check-coverage  ·  alt-audit
                     │  统一 JSON 契约（本节 19.2）
③ 渲染层      CLI 表格 · Markdown 报告 · 静态 HTML 报告 · Streamlit 看板
```

**硬约束**：渲染层**永远不直接读 Parquet**（除展示单表切片摘要时经 `reader`）——一律经②层的 JSON。理由：

1. 口径唯一：看板上的数字与体检命令的数字必然一致（同一份 JSON）。
2. 布局不可知（INV-8）：看板不关心 `by_year`/`single`/`by_code`。
3. 性能隔离：重扫描只发生在②层，渲染层可缓存。

---

## 19.2 视图数据契约（图表层只认契约）

| 契约字段 | 类型 | 来源命令 | 说明 |
|---|---|---|---|
| `table` / `domain` | string | `db-schema --json` | 表名与所属数据域（11 域，05 §9.6） |
| `layout` | enum | `db-schema --json` | `by_year` / `single` / `by_code` / `mixed` |
| `files` / `rows` / `size_mb` | int/float | `db-schema --json` | 体量三要素（README 快照表同源） |
| `date_col` / `date_min` / `date_max` | string | `db-schema --json` | 日期列与覆盖区间 |
| `n_columns` / `columns[]` | int/list | `db-schema --json` | 列清单（PoC-1 后含 dtype/unit/nullable/enum） |
| `gap_category` | enum | `db-audit --json` | `日更` / `豁免` / `周期`（09 §14.2） |
| `missing` | int | `db-audit --json` | 该表应有未完成任务数 |
| `dups` | int | `db-audit --json` | 按判重主键的重复行数（应恒为 0） |
| `ckpt_state` | enum | `ckpt --show --json` | `done` / `partial` / `failed` / 虚记 |
| `fresh_days` | int | `freshness --all` | 相对最近交易日的滞后天数 |
| `slo` | object | 汇总层（K3） | 6 项库级 SLO 打分（09 §14.10） |

**契约纪律**：

1. **只读**：所有视图数据层命令必须只读或 dry-run（09 §14.1 纪律 1）。
2. **来源标注**：任何视图/报告必须在页脚或标题处标注**数据截止时间**（`date_max` 的全局最小值）与**命令来源**。
3. **不可解释即异常**：视图中出现"无法归因的差异"（如行数突变无对应变更）→ 必须在视图上显式标红，而非静默画图（15 §27.2）。

## 19.3 库状态与体检看板（Streamlit）

**定位**：把 `db-audit` / `freshness` / `ckpt --show` / `db-schema` 的结论**一页看完**。**按需启动**（需常驻进程，不作为在线服务；07 §12.8 结论）。

### 页面设计（建议 5 页）

| 页面 | 内容 | 数据来源 | 关键交互 |
|---|---|---|---|
| P1 总览 | 6 项 SLO 打分卡 + 库规模四要素（目录/文件/体积/行数）+ 数据截止时间 | 汇总层 | 点击卡片下钻到明细 |
| P2 新鲜度 | core 7 表 + 全表滞后天数条形图；停更表单独色块（灰） | `freshness --all` | 按滞后阈值筛选；停更/豁免可切换显隐 |
| P3 缺口与重复 | 缺口按三类（日更/豁免/周期）分色柱状；重复行数表（应为空） | `db-audit --json` | 点表名看任务清单；导出缺陷清单 |
| P4 断点与一致性 | 断点 vs 磁盘交叉核对结果；`partial`/`failed` 高亮 | `ckpt --show --json` | 点表看断点历史与差异明细 |
| P5 体量与热点 | Top5 体积/行数/文件数（05 §20.3）；按域聚合饼图；年增趋势（需基准记录） | `db-schema --json` + `bench_log.jsonl` | 切换"体积/行数/文件数"口径 |

### 刷新与部署

| 项 | 约定 |
|---|---|
| 刷新 | 手动刷新（按钮）+ 每日日更后自动生成一次快照（缓存 JSON，非实时查询） |
| 缓存 | ②层 JSON 产物落 `metadata/` 下带日期文件，看板优先读当日缓存（避免每次重扫全库） |
| 启动 | `streamlit run tools/db_dashboard.py`（按需；不设开机自启） |
| 只读保证 | 看板代码**禁止** import 写侧模块（落盘器/backfill）；可由 R1 类断言机检 |
| 权限 | 仅本机访问（`localhost`），不对外暴露端口 |

**现状**：尚无看板（gap）。当前等价物 = `db-report` 生成的 Markdown/文本报告 + CLI 输出。K3（11 §16.2）即本页的最小实现。

## 19.5 报告结构（日报 / 周报 / 体检报告）

### 日报（日更后自动生成，推送摘要）

| 节 | 内容 | 数据来源 |
|---|---|---|
| ① 结论行 | "今日更新 N 表 / 失败 M 表 / 告警 K 条"（一句话） | 日更日志汇总 |
| ② 更新明细 | core 7 表 + extend 34 表的结果（成功/跳过/失败） | 日更日志 |
| ③ 异常与告警 | 权限告警（漏网命中）、限频、截断、恢复动作 | `LEAKY_PERMISSIONS` 命中 + 日志 |
| ④ 库状态 | 数据截止时间 + SLO 打分（1 行） | 汇总层 |
| ⑤ 披露 | 数据来源、命令、时间戳、`db_version` | 元数据 |

### 周报（每周）

日报内容 + 缺口三类统计 + 体量变化 + 停更清单复核 + 本周 `regress` 结果。

### 体检报告（按需，`db-report`）

固定章节：规模 → 布局分布 → 各域明细表（即 05 §20.2 的字典型视图）→ 异常清单 → 附录（命令与口径）。

**共同纪律**：

1. **强制披露节**：不含"来源 + 时间 + 版本"的报告不得对外引用（INV-10）。
2. **数字零手抄**：所有数字由②层 JSON 渲染（ADR-12）——报告生成脚本与文档生成脚本**共用同一渲染逻辑**。
3. **异常置顶**：阻断级异常必须出现在报告第一节，不得埋在附录。

## 19.6 四入口行为契约

| 入口 | 形态 | 适用 | 行为契约 |
|---|---|---|---|
| CLI | 终端文本/表格 | 维护者日常 | 退出码语义有效；`--json` 提供机读输出 |
| Markdown 报告 | 文件，可 diff | 版本留痕、存档 | 每份带日期与 `db_version`；可 diff 出"变化" |
| 静态 HTML | 单文件，可分享 | 评审/汇报 | 自包含（无外链依赖）；内嵌数据快照（打开即当时状态） |
| Streamlit 看板 | 常驻交互 | 探索与下钻 | 只读；按需启动；不对外暴露 |

**一致性要求**：四入口的同一指标必须来自**同一 JSON 字段**；若 HTML 与看板数字不一致，视为缺陷（不是"缓存差异"）。

## 19.7 插件化与降级

| 机制 | 说明 |
|---|---|
| 视图注册 | 新增页面 = 新增一个"JSON 契约消费者"，不改②层 |
| 数据缺位降级 | 某项 JSON 不可得（如看板无当日缓存）→ 显示"数据不可用 + 上次可用时间"，**不得画空图或旧图冒新图** |
| 阈值外置 | SLO 阈值、滞后阈值、体积告警线 → 放 `config.py`（唯一真源），视图中只读 |
| 渲染失败不掩盖 | 图表渲染异常必须显式提示，禁止"静默跳过该图"（同 15.5 "静默失败即违规"） |
