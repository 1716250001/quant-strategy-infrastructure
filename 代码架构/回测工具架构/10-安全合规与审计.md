# 10 安全合规与审计

> **本文档描述 btf 当前的安全模型与审计能力**——对应实现版本 **btf 1.1.0（2026-09-29 定版；2026-09-30 CLI 收编）**。
> 定位：**单人本机工具**，不对外提供任何服务（无网络端口、无多租户、无在线 API）。
> 关联：产物与凭证流转见 [08](08-可复现性与实验管理.md)；依赖预算与门禁见 [14](14-工程化专项设计-上.md)。

---

## 15.1 威胁模型（当前）

| 威胁 | 现状 | 缓解（已落地） |
|---|---|---|
| **策略逻辑外泄** | 策略代码与规则参数是核心资产 | **始终不公开托管**；报告可脱敏（`mask_config`）；**1.0.0 定版 + 1.1.0 CLI 收编（2026-09-30）**，私有库 push 为老大动作 |
| **凭证泄漏**（Tushare token 等） | 采集侧凭证不在 btf 内；btf 只读数据文件 | btf 不读取任何密钥文件；运行期环境仅透传 **`BTF_*` 白名单**（其余环境变量不进配置层） |
| **数据文件被误写** | 主库是全系统共享资产 | btf **只读**主库（代码层约定 + `memory_map` 仅主库）；产物写独立目录 |
| **产物被误改/半成品当真** | 结论可信性的根基 | 原子写 + fsync；manifest 状态机（`RUNNING`/`COMPLETED`/`FAILED`）；`bt verify` digest 双对账 |
| **依赖投毒/膨胀** | 供应链风险 | 依赖最小集 + `tools/deps_budget.py` 常跑门禁 |
| **路径/编码陷阱**（中文路径、GBK 误读） | 本机路径含中文 | 全部 I/O 显式 UTF-8；冒烟测试专测中文路径 |

**非威胁（明确不在模型内）**：远程攻击、越权访问、多用户隔离——**无服务端**，不适用。

## 15.2 密钥与环境隔离

| 机制 | 说明 |
|---|---|
| 环境白名单 | `btf.app.filter_btf_env()`：**只有 `BTF_*`** 前缀变量进入配置层；其余（含可能的 token）不参与 |
| 不采集凭证 | btf 不调用 Tushare API（数据由采集侧流水线写入本地文件），故**无需 token** |
| 配置脱敏 | `mask_config` 用于报告/日志输出；`manifest.config_effective` 为脱敏后的生效配置（复核用） |
| 路径可覆盖 | `BTF_DATA_DIR` / `BTF_OUTPUT_DIR` / `BTF_ALT_DATA_DIR`（避免硬编码绝对路径） |

## 15.3 权限模型

- 当前：**操作系统账户级**（单机单人）；无应用层 RBAC/ABAC。
- 预留：多角色需求出现时再引入（**不承诺时间表**）；领域层与产物契约不阻碍其扩展（鉴权属入口层职责）。

## 15.4 审计：以"可复现"代"门禁"

btf 的审计能力**不是**操作流水账，而是"**结论可追溯到四版本**"：

| 审计问题 | 可回答的手段 |
|---|---|
| 这个结论是**哪份数据**跑出来的？ | `manifest.data_version`（实算指纹 + 逐表行数/日期范围/锚点） |
| 是**哪版代码/配置/规则**？ | `code_version` / `config_hash` + `config_effective` / `rules_version` + `rules_overrides` |
| 过程**是否被降级/采样**？ | `assembly_notes` + 报告「假设与披露」**强制章节**（覆盖度降级、事件采样、空风控链、零成本、内存指纹） |
| 结论**能否复算一致**？ | `metrics_digest` + `bt verify` 双对账 + 事件流可回放 |
| **改动影响范围**？ | 规则四方机检 + 状态分布锚点 + digest diff（升级前后对照） |

**纪律**：凡"承诺披露"的字段必须至少一次取到**非占位真值**（缺数据时显式标注来源，如 `sha256:in-memory:Nsym`，不得写 `unknown` 兜底）。

## 15.5 合规预留（A 股程序化交易）

- 定位：btf 是**回测工具，不接实盘**（非目标）；因此不涉及报备/风控外部要求的直接适用。
- 预留：若未来接实盘通道（远期，不承诺），须满足的最低集——① 订单可追溯（已有：确定性订单号 + 事件流）；② 风控不可绕过（已有：预交易链 + `allow_empty_chain` fail-closed）；③ 变更留痕（已有：CHANGELOG + 基线刷新历史 + 门禁摘要）。
- **不做**：合规报备工具、投资者适当性、账户体系。

## 15.6 当前取舍总表

| 维度 | 现在的做法 | 明确不做（及理由） |
|---|---|---|
| 服务暴露 | 无网络服务、无端口 | Web/API 服务（单人本机；且策略逻辑敏感） |
| 多用户 | 单用户单进程 | RBAC/多租户（成本 > 收益） |
| 凭证 | 不需要（不调 API） | 密钥管理服务 |
| 数据写权限 | 只读主库 | 数据修复工具（修复属采集侧职责） |
| 产物保护 | 原子写 + fsync + 状态机 | 加密存储（本机单人；未来若迁云端再评估） |
| 审计 | 四版本 + digest + 强制披露 | 操作日志库/审计服务 |
| 代码托管 | **不公开**；**1.0.0 私有 GitHub**（就绪）+ **定版日冷备已执行** | 公开仓库（策略敏感） |
