## 第 22 章 性能、容量与成本

### 22.1 实测基线（本机，隔离）

| 场景 | 实测（**隔离单跑**，2026-10-06 RC 后复跑） | 门槛（软 / 硬） | 余量 |
|---|---|---|---|
| B1 十年数据就绪（迭代交易日，不物化截面） | **8.71s** | 10.0s / **14.0s** | 1.6x（软目标内） |
| B2 沪深300 轮动月调仓 10 年（1 标的） | **14.37s** | 15.0s / **20.0s** | 1.4x（**软目标内**——较 1.0 定版态 16.95s 回落） |
| B3 全市场 10 年回测（全链路） | **36.0s** | — / **60s** | 1.66x |
| B4 参数扫描 1000 组外推（8 进程） | **1350s** | — / **1800s** | 1.33x（较定版态 1.08x **改善**） |
| LIQ 十年预计算（区间指标） | **3.89s** | 5.0s / **8.0s** | 2.06x（软目标内） |
| CC 数据不变量校验（20 标的 × 1 年 + 7 组负向对照） | **PASS**（进程内 2.12s） | — | — |

> **RC 批次后复测：已完成（2026-10-06，§66.10 收口批）**——RC-01/02/04 已交付（默认成本非零 / `fund_adj` 路由），
> 上表为 **RC 后隔离复跑**实测（逐项顺序单跑、无并发；B1 软目标内、**B2 回到软目标内**、B4 由 1670s **降至 1350s**）。
> **历史对照（1.0 定版态）**：B1 8.86s · B2 16.95s · B3 43.3s · B4 1670s · LIQ 4.90s；机器态漂移与 OBS-4/5 见 `tests/perf/BASELINE.md` §六。
> 复测锚点与 A/B 对照口径见 [09 §14.10](09-测试验证与基准.md)。

> **机器态说明（OBS-4 / OBS-5，见 [09 §14.8](09-测试验证与基准.md) 与 `tests/perf/BASELINE.md` §六·B）**：
> 本机当前态较 2026-09-27 基线整体偏高（B4 +2.5x），**门槛未放宽**；**L5 须隔离单跑**
> （并发时 B4 假失败：22.5s → 外推 1871s）。

### 22.2 三条性能纪律（都是"踩过坑才立"的）

| # | 纪律 | 为什么 |
|---|---|---|
| 1 | **装配期只做回测必需的事**；披露/审计类计算推迟到**落盘路径** | 数据指纹一度接在 `build()` → 网格**每组合**各付一次（10 年 6 表 ≈7.2s）→ B4 外推 664s → **3647s**（超预算）；改为落盘路径计算后当前机器态 **1670s** |
| 2 | **新增"每次装配都要付"的开销：先量后接**，并给出对 B2/B4 的增量 | 同上；单点小开销 ×1000 组会放大成小时级 |
| 3 | **门槛必须软/硬双档**，回归守卫交给**机器无关断言** | 墙钟门槛在负载下会假失败；IO 装载计数（`loads ≤ 40`）、语义等值、状态分布锚点是机器无关的真守卫 |

### 22.3 关键优化手段（已落地）

| 手段 | 效果 |
|---|---|
| **谓词下推**（`read_year_where(filters=…)`） | 子集宇宙免扫全市场年表（B4 从分钟级降到秒级） |
| **惰性截面**（`_LazyCrossSection`） | 十年全市场免物化 ~8M Bar |
| **年表缓存 + 按日索引**（`YearTableStore`） | 年推进模式下命中率最高；`day_map` O(1) |
| **淘汰只在年切换时触发** | 原先每 bar 全键扫描 → 现在 ≤10 次/十年 |
| **有界缓存**（`BoundedDict` ×5） | 消除无界增长（原 `_ymd_cache` 等无上限） |
| **跨组合共享数据源**（optimize initializer 预热） | B4 11.1s → **7.0s** |
| **区间化**（`corporate_actions` 回看 5 年 + memo） | 全 37 年读 → 区间读（超集等价性有单测：33,451 条逐条一致） |
| **事件日志延迟编码** | 采样模式不再"省盘不省 CPU" |

### 22.4 容量与成本

- 磁盘：主库 GB 级（只读）；产物按 run 累计（JSONL 为主，事件日志可采样压缩规模）。
- 内存：单次回测峰值由"截面 + 年表缓存（≤4 条）"决定；无全库载入路径（ADR-2）。
- 时间：十年全市场分钟级；千组扫描 ~10 分钟（8 进程）。

## 第 23 章 回测-实盘一致性（非目标，仅接口预留）

- **当前明确不做**：实盘/模拟盘通道（NG2）；不承诺时间表。
- **已具备的一致性前提**（未来若接入可直接复用）：
  1. **同一策略类**（`StrategyBase`）+ 同一目标仓位语义（信号-执行分离）；
  2. **同一风控链**（预交易规则链 + fail-closed 语义）；
  3. **确定性标识**（订单号 `O%08d`、成交序号）与事件流 → 可用于"回测 vs 模拟"逐事件 diff；
  4. **四版本锁定**（数据/代码/配置/环境）→ 差异归因有基准。
- **未来接入时必须补的**：成交模型一致性验证（撮合假设 vs 实际成交）、拒单语义对齐、时区/交易时段处理、断线恢复与幂等下单。
- **不做**：券商 API 适配、资管合规流程。

## 第 24 章 市场微观结构与执行建模（当前实现）

| 约束 | 实现 | 口径要点 |
|---|---|---|
| **涨跌停** | 买涨停拒（`limit_up`）、卖跌停拒（`limit_down`）；限价单按 `[down, up]` 校验 | 幅度由**板块**决定（主板 10% / 创业 `300·301·302` 20% / 科创 `688·689` 20% / 北交所 `4xx·8xx·920` 30% / ST 5%）；触及判定容差 **1e-4（相对）** |
| **停牌** | `suspend_d` 在表即停牌 → 拒单（`suspended`） | **全日停牌**（`S` 型且无 `timing`）当日无行情行；盘中停牌当日有行（可交易时段外不成交） |
| **T+1** | 买入当日 `available=0`，次日释放 | 卖出下单受 `available` 硬约束（不是撮合层事后拒绝） |
| **整手** | 100 股取整；不足一手 → 拒单（`lot_size`） | 卖出的零股（送股产生）按实际可卖数量处理 |
| **ST / 退市** | ST 判定由 `namechange` 区间合成；退市由 `stock_basic` 判定 | `tradability` 规则可配 `reject_st`；退市标的保留在库内（防幸存者偏差） |
| **成交时机** | `next_open`（次日开盘）为缺省；同日先卖后买 | bar 内时序显式化为 10 步（[06 §10.2](06-核心流程与关键时序.md)） |
| **成本** | 佣金（含最低 5 元）+ 印花税（卖出，**2023-08-28 分段**）+ 过户费（沪深双向，分段） | 全部经 `tiered_v1` 日期分段实现；`flat_rate` 为简化对照；构造参数经 `cost_model_params` 注入（✅ RC-05 已交付，成本敏感性可扫） |
| **滑点** | `none` / `fixed` / `pct` / `sqrt_impact` | **缺省 `pct 0.001`（单边 10bp，业界保守下限）**（RC-01，已交付 2026-10-05）；显式 `none` 仍可用但装配期 warn；报告**读生效配置**渲染（RC-03，已交付）；**规模相关滑点 `sqrt_impact`**（RC-12，已交付；η·σ·√(Q/V) + cap，**默认关闭**） |
| **成交量参与率上限 VPP** | `handler_params.volume_participation`，**缺省 `0.05`**（RC-02，已交付） | 单笔成交 ≤ 当日成交量 × 5%，超出部分**缩量**至上限；缩到不足一手 → `volume_cap` 拒单。显式 `null`/`{}` = 不启用（保留显式语义）；**本节早先只写"要求"，代码却默认关闭 —— 已按 RC-02 改齐** |

**不做（明确）**：盘口排队位置、**盘口级微观结构/逐笔冲击**（规模相关滑点 RC-12 已交付 ≠ 盘口建模）、集合竞价撮合细节、涨跌停"排队买不进"的概率建模。
**已不再是"不做"**：**部分成交（按量上限缩量）**——VPP 自 RC-02 起**默认启用**（此前默认关闭 ⇒ 等价"以开盘价无限量成交、零冲击"）。

> **交付状态（2026-10-05）**：**RC-01 / RC-02 / RC-03 / RC-05 / RC-12 均已交付**（滑点缺省 `pct 0.001`、VPP 缺省 `0.05`、
> 报告读生效配置、`cost_model_params` schema 可达且 `--set`/`--grid` 可注入、`sqrt_impact` 注册且**默认关闭**）——
> 上表对应行为**均为现状**。本表**无未交付项**。

**建模原则**：**宁可保守也不要乐观**——无法建模的约束以**拒单**表达（而不是假设成交），并在报告中披露所用假设。

## 第 26 章 数据治理、契约与血缘

### 26.1 数据治理三条底线

1. **只读主库**：btf 不写任何数据文件；修复属采集侧职责。
2. **登记即契约**：新增表必须先在 `tables_meta.TABLES` 登记（布局/日期列/主键/起点/量纲），否则读取层拒绝。
3. **量纲单点换算**：单位换算只在 `parquet_reader` 发生（消费侧不得各自换算）。

### 26.2 数据契约四件套

| 契约 | 内容 | 守卫 |
|---|---|---|
| **表登记** | **20 表**三布局（BY_YEAR/SINGLE/METADATA；RC-04 新增 `fund_adj`（序号 19），已交付 2026-10-05；R32′ 新增 `fund_div`（序号 20）——2026-10-08；第 21 项 `fund_share` **不注册**：仅披露、禁判折算） | 读取层按登记解析（未登记即报错） |
| **覆盖度** | 必需表起点（`stk_limit ≥ 2008-01-02`）+ 降级表（`etf_limit`/`adj_factor`）+ **ETF 复权条件降级**（`fund_adj ≥ 1999-10-22`，仅 ETF 宇宙触发） | 装配期硬门 + `allow_degraded_limit` 显式放行并披露 |
| **不变量** | CC-1..CC-5（OHLC/涨跌幅/日历/因子/量价） | 装配期门（`strict` 可硬失败）+ 产物 + 机检（含负向对照） |
| **内容指纹** | `sha256` 内容寻址（三档 meta/fast/full） | 落盘路径实算 + 变异性检查 + fail-closed（不得回落占位值） |
| **复权因子消费（1.2.4，R62′/N64）** | `AdjustService` 按 `factor_table_of` 路由装载；**因子行进程级共享缓存**（键 `{root}\|{symbol}`；首载 1.5–1.9s/标的、重复 ≈0.04s/标的——网格/滚动验证不再线性放大）；**缺失登记/告警逐实例**（`degraded_notes` 披露不因缓存命中而丢） | 引擎消费侧视图单测（E1 PIT/E3 记账侧名义价/E7 五反例）＋ 缺失披露用例 |
| **公司行动清单（1.2.0，CL-2）** | 离线探针（`adj_factor` 跳变 ∩ 分红排除 ∩ akshare 快照关联）→ `btf_datasets/corp_actions/corp_actions.json`（**来源快照 sha256**＋统计；**正推校验＋放大因子守卫**；挂起条目附股本级披露 `r_effective`/认购率——N19；缩股门槛后 0 存活全量保留披露——N17） | 清单校验单测（正推/守卫/known-16/000816·002232 入建模）＋ 消费端披露（未加载显式） |

### 26.3 血缘（可追溯链）

```mermaid
flowchart LR
    RAW[("主库原始表")] --> REG["tables_meta 登记"]
    REG --> RD["parquet_reader：布局归一 + 量纲换算"]
    RD --> STORE["YearTableStore：缓存/索引（唯一 IO 入口）"]
    STORE --> SVC["领域服务：feed / state / adjust / quality / version"]
    SVC --> ENG["引擎：截面 + 状态面板"]
    ENG --> OUT["产物：事件/成交/快照/指标/质检报告"]
    OUT --> REP["报告（含数据指纹 + 披露）"]
```

**血缘可用于**：某结论 →（指纹）→ 哪些表/哪些年文件 →（登记）→ 哪些原始表。**粒度**：表级（不追踪行级血缘）。
