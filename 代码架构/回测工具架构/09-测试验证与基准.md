# 09 测试验证与基准

> **本文档描述 btf 的测试体系与性能基准（含实测数字）**——对应实现版本 **btf 1.1.0（2026-09-29 定版；2026-09-30 CLI 收编）**。
> 关联：门禁清单见 [README.md](README.md) 与 [16](16-架构评审与验收标准.md)；性能门槛取值依据见 `代码/btf/tests/perf/BASELINE.md`。
> **证据纪律**：凡声称"通过"，须给「命令 → 实测输出摘要」；**禁止**以"全绿"替代摘要（本纪律由历次审查沉淀，见 [19](19-架构审查与重构方案-20260927.md) §6.3）。

## 14.1 测试分层（五层，与 `pyproject.toml` 标记一一对应）

| 层 | 标记 | 目录 | 语义 | 规模 |
|---|---|---|---|---|
| **L1** | `l1` | `tests/unit/` | 单元测试（秒级，提交门）：领域对象、撮合规则、指标、配置、报告渲染 | 29 个文件 |
| **L2** | `l2` | `tests/integration/` | 集成测试（`MemoryFeed` 组合行为）：装配、风控链、规则对账、CLI/API、指纹、质检门 | 22 个文件 |
| **L3** | `l3` | `tests/system/` | 系统测试（端到端对账）：真入口（`bt run` → 落盘 → `bt report` → `bt verify`） | 3 个文件 |
| **L4** | `l4` | `tests/regression/` | 回归测试：黄金集 + 双跑 diff | 6 个文件 |
| **L5** | `l5` | `tests/benchmark/` + `tests/perf/` | 性能基准：B1–B4 + LIQ 预计算 | 6 个文件 |
| — | `smoke` | `tests/test_smoke.py` | 冒烟（中文路径/环境） | 10 用例 |

**总量：890 测试**（`pytest --collect-only`）。运行方式：

```bash
bt test --layer l1            # 单层（l1..l5 / all）
bt test --layer all -k 关键词  # 按表达式筛选
bt check                      # 九项常跑门禁（= python tools/check.py 单一真源；见 §14.9）
```

## 14.2 单元测试要点（撮合与约束全覆盖）

| 主题 | 关键断言（方向） |
|---|---|
| 撮合 | 涨停买入拒（`limit_up`）、跌停卖出拒（`limit_down`）、停牌/无行情拒（`suspended`）、非整手拒（`lot_size`）、现金不足拒（`insufficient_cash`）、**卖先买后**顺序 |
| T+1 | 当日买入 `available=0`、次日可卖；跨越停牌日的可卖释放 |
| 成本 | 佣金最低 5 元、印花税**日期分段**（2023-08-28 前后）、过户费沪深双向分段、滑点三态 |
| 除权 | `ex_date`/`pay_date` 两时点分发；现金到账与份额调整各自入账 |
| 状态面板 | 六源合成（限价/停牌/ST/退市/行情）；`tradable` 与触板判定（容差 1e-4） |
| 指标 | 15 项指标的定义与边界（n<3 的业务异常、不可算项 `null`） |
| 规则 | 三内置规则裁决三态（`ALLOW`/`REDUCE`/`REJECT`）+ 缺数据 `strict` 语义 |
| L0-LIQ 状态机 | **序列推进测试**（逐日回灌）：`CRISIS → RECOVERY×3 → NORMAL`；长平静期零 RECOVERY |
| 配置 | Schema 拒绝未知键（死键即失败）、四层合并与 `--set` 类型推断、脱敏 |
| 报告 | 渲染级结构（标签成形、转义双向探针）、强制章节不可关 |

## 14.3 对账测试

- **指标复算**：由 `snapshots.jsonl`/`fills.jsonl` 独立复算指标，与 `metrics.json` **差 0**。
- **digest 双对账**：`bt verify` 同时校验「按产物重算 vs 落盘」与「落盘 vs manifest 记录」。
- **双跑一致性**：同配置重跑 → `metrics_digest` 逐位相同；网格「进程池 vs 进程内单跑」指标逐位一致。

## 14.4 黄金数据集回归（L4 核心）

- 位置：`btf_datasets/`（由 `python tools/build_golden.py --cases all [--verify]` 构建/校验；`bt dataset` 为其封装）。
- 覆盖场景：成交约束、成本分段、分红送股、退市与 ST、T+1、再平衡、指标口径。
- 纪律：校验失败**拒绝写入**（`--force` 才覆盖并留痕）；黄金集是"结论可信"的**第三层证据**（① 单测/集成 → ② 数据不变量 + 渲染级断言 → ③ 黄金集回归）。

## 14.5 前视偏差与 PIT 防线（当前实现）

| 防线 | 实现 |
|---|---|
| 时序显式化 | 日循环 **10 步**全序 + 每日事件序固定（[06 §10.2](06-核心流程与关键时序.md)） |
| PIT 数据 | 指数宇宙取 `index_weight` **月末快照**复算；财务指标按 `ann_date` 匹配；宇宙按当日 `universe(date)` |
| 决策价可达性 | 风控在决策时点使用**当日盯市价**（`mark_all` 标记整截面）——避免"用昨日价审批今日单"的伪约束 |
| 未做（明确登记） | 独立 AST「越界取数」扫描器——当前以时序单测 + PIT 断言替代，属能力演进项 |

## 14.6 btf vs md_core（赤潮决策侧）口径对齐

| 机制 | 位置 | 断言 |
|---|---|---|
| 规则数值四方一致 | `tools/check_rules_four_way.py` | 源 ↔ 镜像 ↔ 消费绑定 ↔ btf 缓存 |
| 状态机语义锚点 | 同上 | 源「3 日恢复」× md_core「连续 3 日 status」× btf `_finalize` 窗口结构 + **自我维持回归守卫** |
| 规则链对账 | `tests/integration/test_v77_align.py` | 逐日状态/买点与镜像口径一致 |
| LIQ 分布锚点 | `tests/system/test_v77_full_range.py` + `tests/perf/test_liq_precompute.py` | NORMAL/RECOVERY 占比与**连续段长上限**（互为区间/十年双锚点） |

## 14.7 第一验收场景测试

- **奇点战法（ETF 轮动）**：`tests/system/test_example_rotation.py`（真入口）+ 样例配置（`examples/`）；示例端到端须产生成交（防"零订单却报成功"）。
- **v7.7 规则回归**：规则加载（镜像）+ L2 硬筛子 PIT + L0-LIQ 闸门序列 + 买点双条件。
- **CLI 基准端到端**：`tests/system/test_cli_benchmark_e2e.py`——`bt run`（含 `report.benchmark`）→ `bt report` → `bt verify` 四步真入口，且报告为**渲染级断言**。

## 14.8 性能基准（L5，实测）

| 基准 | 场景 | 软目标 | 硬门槛 | 实测（本机，**隔离单跑**；2026-09-29 1.0 定版态） |
|---|---|---|---|---|
| **B1** | 十年数据就绪（迭代 2431 交易日，不触发截面物化） | 10.0s | **14.0s** | **8.86s** |
| **B2** | 沪深300 轮动月调仓 10 年 | 15.0s | **20.0s** | **16.95s** |
| **B3** | 全市场 10 年回测（含撮合/风控全链路） | — | **< 60s** | **43.3s**（余量 1.39x） |
| **B4** | 参数扫描 1000 组外推（8 进程） | — | **< 1800s** | **1670s**（余量 1.08x） |
| **LIQ** | L0-LIQ 十年区间预计算 | 5.0s | **8.0s** | **4.90s** |
| **CC** | 数据不变量校验（20 标的 × 10 年） | — | — | **0.45s PASS**（全市场十年独立复跑 119.2s） |

**门槛纪律（写入 `tests/perf/BASELINE.md`）**：墙钟门槛一律**软目标 + 硬门槛**双档（软目标=原始设计目标，超出仅告警；硬门槛保证负载机不假失败）；
**真正的回归守卫是机器无关断言**——IO 装载计数（`loads ≤ 40`）、语义等值、状态分布锚点、digest 一致性。
**L5 必须隔离单跑（OBS-5）**：与其它 pytest 并发时 B4 会假失败（22.5s → 外推 1871s，余量 0.96x）；
跑 L5 前确认无并发 `python` 进程；**预算 1800s 是需求，不因机器态放宽**。

## 14.9 测试运行纪律与九项常跑门禁

**`python tools/check.py` —— 9 项**（退出码 0 = 全绿）：

| # | 项 | 脚本/方式 |
|---|---|---|
| 1 | ruff lint | `ruff check btf tests tools` |
| 2 | 架构铁律 | `lint-imports`（**10 契约**） |
| 3 | 冒烟测试（中文路径/环境） | `pytest tests -m smoke` |
| 4 | 依赖预算 | `tools/deps_budget.py` |
| 5 | 包可导入 | `python -c "import btf"` |
| 6 | domain 白名单 | `tools/check_domain_whitelist.py`（AST 穷举） |
| 7 | 报告渲染级结构 | `tools/check_report_render.py`（**含负向对照**） |
| 8 | 数据不变量校验 | `tools/check_data_quality.py`（**负向对照 5/5 注入缺陷必检**） |
| 9 | IO 单一入口（EX-4 完全体） | `tools/check_io_boundary.py`（AST 扫描：`pyarrow.parquet`/`parquet_reader` 仅 `core` + `parquet_reader` 可用；`--self-test` 变异性自检） |

**纪律**：

- 无 CI 服务器（单机），以**本地常跑门禁**替代；每批交付必附门禁实测摘要。
- 机检类断言必须**可被证伪**：即"故意破坏被保护对象 → 断言必须变红"，破坏后仍恒绿者判为伪防线、不得计入防线。
- 交付物是渲染/序列化产物时，断言必须落到**渲染后的结构**（禁止只断言源文本子串）。
- 披露字段（指纹/版本/质检）必须**至少一次取到真值**，恒为占位值即视为缺陷。
