# 07 技术选型建议与权衡

> **本文档给出 btf 当前实际技术栈与选型理由**——对应实现版本 **btf 1.1.0（2026-09-29 定版；2026-09-30 CLI 收编）**。
> 原则：**单人可维护 > 生态丰富 > 性能极致**；不引入编译型依赖、不引入服务端组件。
> 关联：[03](03-总体架构方案对比与推荐.md)（分层）、[14](14-工程化专项设计-上.md)（门禁与依赖预算）。

---

## 12.1 语言与运行时

| 项 | 选型 | 理由 / 权衡 |
|---|---|---|
| 语言 | **Python 3.13**（venv） | 与现有数据/研究工作流同构；单人维护成本最低；**不引入编译型扩展**（无 Rust/C++ 构建链） |
| 包管理 | venv + `pyproject.toml` + 依赖预算门禁 | `tools/deps_budget.py` 常跑（防依赖膨胀）；环境路径可经 `BTF_*` 覆盖 |
| 入口 | `bt` CLI（console_scripts）+ `btf.api` | CLI 面向操作，API 面向脚本/Notebook；两者**同源实现**（`btf.app`） |

**权衡**：放弃"多语言内核/DSL"（NG8）——单人维护下，语言内 DSL 的收益小于其治理成本。

## 12.2 数据处理与内存计算

| 层 | 选型 | 理由 |
|---|---|---|
| 列式数据 | **PyArrow**（`pa.Table`） | Parquet 原生、零拷贝切片、谓词下推（`filters=[("ts_code","in",…)]`）——子集宇宙免扫全市场年表 |
| 数值计算 | **NumPy** | 指标/校验中的向量化（如 CC-4 单调性、指标序列） |
| 表格便利 | **pandas**（**仅研究侧/测试夹具**） | 引擎热路径**不依赖 pandas**（避免隐式拷贝与 dtype 陷阱） |
| 惰性截面 | 自研 `_LazyCrossSection` | 逐日截面只构造必要字段，十年全市场免物化 ~8M Bar |
| 缓存 | `YearTableStore`（年表 FIFO，缺省 4 条）+ `BoundedDict`（LRU，上限显式） | 年推进模式命中率最高；**所有缓存必须有界**（无界缓存=内存泄漏） |

## 12.3 存储与序列化

| 用途 | 选型 | 说明 |
|---|---|---|
| 行情主库 | **Parquet**（年分区） | 采集侧既有格式；btf **只读** |
| 事件流 | **JSONL**（`events.jsonl`） | 行式、可追加、可采样、可 diff；单行 `{"kind":…,"payload":…}` |
| 成交/拒单/快照 | **JSONL** | 同上；对账与回放的数据源 |
| 指标/清单 | **JSON**（`metrics.json`/`manifest.json`/`data_quality_report.json`） | 严格 JSON（**不可算项写 `null`**，不写 `NaN`） |
| 报告 | **HTML**（自包含，可选内联 Plotly） | 无需服务端即可查看 |
| 写入纪律 | **原子写 + fsync**（文件 + 目录项） | 掉电后"产物可信"是 0.X 阶段唯一的兜底 |

## 12.4 计算与并行

| 场景 | 选型 | 说明 |
|---|---|---|
| 单次回测 | **单进程事件循环** | 确定性优先；实测十年全市场 **32.9s**（门槛 60s） |
| 参数扫描 | **ProcessPoolExecutor**（缺省 8 worker）+ **initializer 预热** | 跨组合共享数据源 memo；Windows spawn 下 worker 为模块级函数（可 pickle） |
| LIQ 十年预计算 | **ThreadPoolExecutor**（pyarrow 释放 GIL） | 逐年并行 + 共享 store（`threading.Lock` 保护缓存，**IO 在锁外**） |
| 不使用 | 分布式 / 消息队列 / 数据库服务 | NG4；日线单机即可（**进程池是唯一并行手段**） |

**性能纪律（已写入 `tests/perf/BASELINE.md`）**：墙钟门槛一律 **软目标 + 硬门槛** 双档（负载机不产生假失败）；**真正的回归守卫是机器无关断言**（IO 装载计数、语义等值、分布锚点）。

## 12.5 消息与事件

- **进程内事件**：7 类 frozen dataclass（[04 §8.4](04-领域模型与核心接口.md)），不走外部 MQ（NG4）。
- **事件日志**：`events.jsonl`，超预算**采样**（尾部 ring + 哨兵行 `kind="_sampled"`）并在 manifest/报告**强制披露**；延迟编码（预算判断前置）避免"省盘不省 CPU"。
- **权衡**：放弃事件总线/异步框架——单人场景下确定性比并发灵活更重要。

## 12.6 调度与任务编排

- 当前：**人工/CLI 驱动**（`bt run` / `bt optimize` / `bt test`）；无调度服务。
- 采集侧日更流水线**独立**于 btf（btf 只读消费）。
- 远期（不承诺）：`automate`/计划任务壳层——**不做**内置调度器。

## 12.7 可视化与报告

| 项 | 选型 | 说明 |
|---|---|---|
| 模板 | **Jinja2**（`autoescape=True`） | 文本字段自动转义；**HTML 片段必须显式 `| safe`**（否则标签被转义，正文不可读） |
| 图表 | **Plotly**（可选依赖） | 缺失时**降级**为内置 HTML/SVG（`render_html` 不抛错） |
| 报告结构 | 6 章：`summary / performance / trading / assumptions / reproduce / appendix` | 配置 `report.sections` 可收窄，但**「假设与披露」「复现说明」为强制章节** |
| 渲染级断言 | `tools/check_report_render.py`（`bt check` 第 7 项） | 断言"渲染后的结构"（`<div class=`/`<table>`/`<script>` + 转义双向探针），**不是**源文本子串 |

## 12.8 实验管理

| 项 | 选型 | 说明 |
|---|---|---|
| 产物存储 | **`local_jsonl`**（`LocalRunStore`） | 无数据库：目录 + JSONL/JSON，天然可 diff/可 audit |
| 元数据 | `manifest.json`（四版本 + 规则版本 + 摘要） | 见 [08](08-可复现性与实验管理.md) |
| 查询 | `list_runs` / `load` / `read_manifest` / `bt verify` | 千级 run 线性扫描足够；DuckDB 仅在未来需要聚合查询时评估 |
| 对账 | `metrics_digest` + 双对账（recompute/stored） | 可复现性的常跑证据 |

## 12.9 配置与校验

| 项 | 选型 | 说明 |
|---|---|---|
| 格式 | **YAML**（`yaml.safe_load`） | 人可读、可注释 |
| 校验 | **JSON Schema**（`backtest.v1`） | 未知键**拒绝**（`additionalProperties: false`）——死键即失败 |
| 分层 | 默认 → `BTF_*` 环境（白名单过滤）→ 文件 → CLI `--set` | 覆盖路径单一（`btf.app` 单源解析） |
| 脱敏 | `mask_config` | 报告/日志中的敏感字段脱敏；生效配置入 manifest |
| 预检 | `bt config-check [--resolve-strategy] [--dump]` | 拼错类名/死键在 run 前暴露 |

## 12.10 测试与质量工具

| 工具 | 用途 | 落地 |
|---|---|---|
| **pytest** | 五层测试（`l1` 单测 → `l5` 基准） | **890 测试**常跑 |
| **ruff** | lint + 格式（零容忍） | `bt check` 第 1 项 |
| **import-linter** | 架构契约（**10 条**） | `bt check` 第 2 项；`Contracts: 10 kept, 0 broken` |
| 自研机检 | 冒烟、依赖预算、包可导入、domain 白名单、报告渲染级、**数据不变量** | `bt check` 第 3–9 项 |
| 基准门槛 | B1/B2/B3/B4 + perf（LIQ） | 软/硬双档，`tests/perf/BASELINE.md` 登记 |
| 插件边界 | 核心文件哈希基线 + 注册点唯一性 + **刷新留痕** | `tools/check_plugin_boundary.py` |

## 12.11 依赖管理与发布

- 运行依赖保持**最小集**（pyarrow / numpy / pyyaml / jsonschema / jinja2 / plotly 可选）；`pandas` 仅供研究与测试。
- 版本：`btf/_version.py` **单一真源**（`__init__` re-export；测试断言二者一致 + 语义化形制）。
- 发布：**1.0.0 已定版（2026-09-29）→ 1.1.0（2026-09-30 CLI 收编）**，**冷备已执行**（定版日 + 1.1.0）；迁 **私有** GitHub（push 为老大动作，本地基线就绪）。

## 12.12 选型总表（一页速览）

| 维度 | 选择 | 放弃项 |
|---|---|---|
| 语言/运行时 | Python 3.13 + venv | 多语言内核、DSL |
| 数据 | PyArrow + Parquet（只读主库） | 数据库服务器、DuckDB（暂不） |
| 并行 | ProcessPool（扫描）+ ThreadPool（预计算） | 分布式、MQ |
| 事件 | 进程内事件 + JSONL 日志 | 事件总线/异步框架 |
| 产物 | local_jsonl + JSON/JSONL + HTML | 事务型存储、对象存储 |
| 配置 | YAML + JSON Schema + 环境白名单 | 手写配置解析器 |
| 可视化 | Jinja2 + Plotly（可降级） | 前端框架/在线仪表盘 |
| 质量 | pytest + ruff + import-linter + 6 自研机检 | 外部 CI（本地门禁替代） |
