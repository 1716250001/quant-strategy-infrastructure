## 第 10 章 核心流程

### 10.1 流程一：历史回测（主旅程）

```mermaid
sequenceDiagram
    participant U as 用户（CLI / api）
    participant C as config（四层合并 + Schema）
    participant RT as BTFRuntime（装配根）
    participant F as DataFeed（主库只读）
    participant Q as quality（CC-1..CC-5）
    participant E as Engine（日循环）
    participant S as RunStore（产物）

    U->>C: bt run --config x.yaml [--set k=v]
    C->>C: 默认 → BTF_* 环境 → 文件 → CLI 覆盖 → Schema 校验 + 脱敏
    RT->>RT: build()：硬门（覆盖率/基准守卫/质检/风控链/档位/插件契约）
    RT->>F: 解析宇宙（PIT）+ 组件装配（插件注入）
    RT->>Q: 数据不变量校验（区间 + 宇宙；strict 可硬失败）
    RT->>S: create_run（骨架 manifest，状态 RUNNING）
    RT->>E: run（逐日 10 步循环）
    E->>S: events/fills/rejections/snapshots（流式落盘）
    RT->>S: metrics.json + data_quality_report.json + manifest 补全（含数据指纹）
    RT->>RT: mark_failed（异常时）后抛出
```

**关键纪律**：

- **落盘先建骨架**：`create_run` 在任何计算之前（失败也有可查的失败现场）。
- **异常即失败态**：引擎/写盘异常 → `mark_failed(reason)` 后抛出（不留下"看似成功"的目录）。
- **指纹在落盘路径实算**（`persist=False` 的内存回测/网格组合零成本）。
- **指标落盘与终端同形**：不可算项写 `null`（严格 JSON），终端同样显示 `null`。

### 10.2 日循环：10 步（引擎内核，`btf/engine/loop.py`）

```mermaid
flowchart TB
    S1["① 公司行动（ex_date 开盘前分发；pay_date 现金到账）"]
    S2["② 撮合：T-1 订单队列 → NextOpenHandler（次日开盘）"]
    S3["③ 逐单 apply_fill（持仓/现金/费用入账；T+1 可卖释放）"]
    S4["④ on_open（策略开盘回调，可读当日状态）"]
    S5["⑤ 收盘重估 mark_all（整截面标记 → 持仓估值）"]
    S6["⑥ on_close（策略收盘回调：设目标）"]
    S7["⑦ Rebalancer.generate_orders（当前 → 目标）"]
    S8["⑧ 风控预检 risk.pre_check（ALLOW / REDUCE / REJECT + 归因）"]
    S9["⑨ 确定性赋号 O00000001… → 订单入队（次日撮合）"]
    S10["⑩ SessionEnd 快照（持仓 / NAV）"]
    S1 --> S2 --> S3 --> S4 --> S5 --> S6 --> S7 --> S8 --> S9 --> S10
```

**每日事件序（确定性）**：`corporate_action*` → `market_open` → `fill*` / `order_rejected*` → `market_close` → `order_submitted*` → `session_end`。

**关键语义（易错点显式化）**：

| 步骤 | 语义要点 |
|---|---|
| ① | 公司行动按**两时点**分发：`ex_date`（份额/成本调整，开盘前）与 `pay_date`（现金到账，仅派息）；两日重合等效单日但**各留一条事件** |
| ② | **卖先买后**（同批订单内的确定性顺序）；停牌/涨跌停/整手/无行情 → 拒单（`RejectCode`） |
| ③ | 成交即入账：持仓 `avg_cost`、现金、费用；**T+1**：当日买入的 `available=0`，次日释放 |
| ④ | `on_open` **可读当日状态面板**（`is_suspended`/`is_st`/限价等），**不得读当日 `close`**（收盘价在 ⑤ 才产生）。**✅ RC-10 已交付（2026-10-05）**：**相位感知**前视封堵——`on_open` 阶段 `ctx.bar()` **拒访** ∧ `history(end ≥ 当日)` **拒**（相位由引擎 `_set_phase` 切换）；`on_close` 阶段两者恢复合法（当日 bar 已收盘，`test_history_within_current_ok` 钉住既有契约）；另有引擎级「`signal_time < execution_time`」**双时间戳断言**（②撮合前，fail-closed；[09 §14.10](09-测试验证与基准.md) #15） |
| ⑤ | `mark_all` 标记**整个当日截面**（不只持仓）——风控在决策时点需要**新建仓标的**的盯市价；未持有标的只进 `_last_close` 不入估值，**NAV 语义不受影响** |
| ⑦ | 再平衡器按配置（`full` / `threshold`）把「当前 vs 目标」转为订单；**策略不下单**（信号-执行分离） |
| ⑧ | 风控链逐条裁决；`REDUCE` 缩量后继续，`REJECT` 立即否决并记录**首个否决规则**（`risk_rejected`，message 含规则名） |
| ⑨ | 订单号确定性赋号（`O00000001…`），与网格/重跑逐位可复现 |
| ⑩ | 快照落 `snapshots.jsonl`（`SessionEnd` 记录），是净值曲线与对账的数据源 |

### 10.3 流程三：参数优化（已交付：网格 + 进程池）

```mermaid
flowchart LR
    G["--grid 解析<br/>（类型推断单源 btf.app）"] --> W["进程池（workers，缺省 8）"]
    W --> I["initializer 预热<br/>（跨组合共享数据源 memo + 模块装载）"]
    I --> R["每组合：load_config → build → run(persist=False)"]
    R --> M["compute_all（指标）"]
    M --> O["按 objective 排序（缺失/NaN 排末尾，不剔除记录）"]
```

- **同一代码路径**：每个组合走 `BTFRuntime` 标准装配与执行（与单跑**逐位一致**，有常跑一致性用例）。
- **不落盘**：组合回测 `persist=False` → 无指纹/无质检产物开销（性能纪律见 [14](14-工程化专项设计-上.md) §BASELINE）。
- **Walk-Forward（10.4）/ 蒙特卡洛（10.5）已交付**（RC-15/16，2026-10-05：`bt validate walk-forward|mc`）——见 §10.4/§10.5 说明。
- **RC-06 已交付（2026-10-05）**：产物与终端输出**试验数 N**（`n_combos` + `--n-trials` 声明数）、`param_dim`、`n_trading_days`、
  **`psr` / `dsr`**（`btf/analytics/inference.py`），并显式打印「N=… 未校正 —— 阈值应 ≤ 0.05/N」；排序与 `rank` 语义**不变**。
  锚点：零信号 432 组 ⇒ PSR 0.9994 / DSR 0.5964（[09 §14.10](09-测试验证与基准.md) #7）。
- **✅ RC-07 / RC-08 已交付（2026-10-05）**：`_run_single` 现传 `extras=rt._benchmark_metrics` —— 配 `report.benchmark` 时每组合含
  IR / 超额等基准相对项（`--objective information_ratio` / `annualized_excess` 可用；未配基准不报错、不新增字段）；
  新增 `--perturb δ1,δ2` 邻域扫描（top1 数值型参数 `p×(1±δ)`，产物含 `range` / `std` / `relative_degradation` /
  `sensitive`，退化 > 50% 时终端提示「疑似过拟合」——**只提示，不替使用者判定**）。
  锚点：尖峰退化 **100%**（敏感）/ 平坦 **10%**（不敏感）；带基准网格 `information_ratio` 入产物（[09 §14.10](09-测试验证与基准.md) #8/#9）。

### 10.4 流程四：Walk-Forward 验证（**✅ RC-15 已交付**，2026-10-05）

- **入口**：`bt validate walk-forward --config <yaml> --window N [--test N] [--step N]`
  `[--mode rolling|anchored] [--purge N] [--embargo N] [--no-persist] [--out json]`。
- **切分（唯一口径）**：只用**交易日历**（真实库走 `trade_cal`；注入型 Feed 用其 `dates`）——
  **禁止随机划分**（模块无随机源，静态可审）；`test_start = train_end + 1 + purge + embargo`；
  rolling=训练窗随折滑动 / anchored=锚定首日逐折加长。
- **执行**：每折走 `BTFRuntime` 标准装配与执行（**与单跑同一代码路径**）；`persist=True`（缺省）时每折落盘，
  且「折号 / 训练窗 / 测试窗 / 参数」经**装配披露进该折 manifest**（"区间可追溯"落地）。
- **输出**：`folds` **全量**（含最差折）+ `summary`（mean/median/**min**/**max**）——不得只报最优；
  OOS 指标与 `bt run` 同口径（含基准相对项）。锚点见 [09 §14.10](09-测试验证与基准.md) #11。
- 归属：L4 推断层的**可见化**工具（不替用户判定策略有效；[15 §27.2](15-工程化专项设计-下.md)）。

### 10.5 流程五：蒙特卡洛稳健性（**✅ RC-16 已交付**，2026-10-05）

- **入口**：`bt validate mc --run <run_id> [--n N] [--seed S] [--out json]`（**读回产物、不重跑引擎**）。
- **三项分布**：① 置换检验（sign/夏普双侧 p 值 + order/最大回撤——顺序敏感项）；
  ② bootstrap 置信区间（夏普 / 几何年化的 p05/p50/p95 + **是否跨 0**）；
  ③ 随机择时对照（"噪声尺子"：同持有天数随机择时分布 + 观测分位；**需基准**，无则 `null` 不伪造）。
- **纪律**：扰动只作用在**收益序列层**（撮合规则逐位不变——产物文件哈希不变，有断言）；
  种子取 `manifest.seed.master` 单源（`--seed` 可覆盖并记来源）；**同种子重跑逐位一致**；结果以分布披露。
- 归属：同上（[09 §14.10](09-测试验证与基准.md) #12）。

### 10.6 职责切分（撮合 / 组合 / 风控 / 分析 / 优化）

| 环节 | 负责模块 | 输入 | 输出 | 不做什么 |
|---|---|---|---|---|
| 取数与状态 | `data`（feed/state） | 主库 + 日期 | 逐日截面 + 状态面板 | 不做交易决策 |
| 撮合 | `execution`（handler/cost/slippage） | 订单 + bar + 状态 | `Fill` 或 `RejectCode` | 不修改目标、不做风控 |
| 组合 | `portfolio` | 成交 + 目标 | 持仓/现金/NAV/快照 | 不生成目标 |
| 目标生成 | `strategy` + `rebalancer` | 截面 + 持仓 | 订单 | 不直接成交、不绕过风控 |
| 风控 | `risk`（规则链） | 订单 + 组合 + 状态 | 三态裁决 | 不做撮合、不改价格 |
| 分析 | `analytics` | 快照 + 成交 | 指标（纯函数） | 无副作用、不读数据源 |
| 优化 | `optimize` | 配置 + 网格 | 组合结果排序 | **不内嵌回测逻辑**（调引擎） |

### 10.7 展示层一致性纪律（易错点）

- **终端 == 落盘**：不可算指标一律 `null`（终端不再出现 Python `nan`）。
- **极短区间告警**：区间 < 20 交易日（`SHORT_PERIOD_TRADING_DAYS`）时打印告警且 **exit 0**——极短区间部分指标"数学有定义、业务无意义"，禁止用于 `optimize --objective` 排序。
- **optimize 短区间门禁（CL-1，1.2.0）**：`bt optimize` 对实算样本 **< 250 交易日**（`MIN_OPTIMIZE_TRADING_DAYS`）**默认阻断（退出码 3、不产出排序）**；显式 `--allow-short` 放行并把 override 记入产物（禁"绕过即静默"）。
- **公司行动日循环（1.2.0，CL-2 第二段）**：日循环步骤 ①（除权处理）在开盘前按事件原子入账——配股 `M=floor(N×r)` 份额＋缴款＋加权成本、缩股 qty 缩减（无现金流）；`RunResult.rights_events/consolidations` 审计＋`assembly_notes` 披露。
- **ETF/LOF 公司行动日循环（1.2.3，CL-2-H／ADR-20）**：同一除权处理点新增两类事件——**份额折算**（`shares ÷= R`、`avg_cost ×= R`，成本守恒；R 取 `pre_close(t)÷close(t−1)` 与 `fund_adj` 跳变**双证据互校**，不符 **fail-closed**）与**分红除息**（`ex_date` 份额不变；`pay_date` 现金到账 `qty_at_ex × div_cash`，回退链 `pay_date→earpay_date→ex_date` 且**回退必须披露**）；同日同标的排序键「**先折算后分红**」（ADR-20 第 ⑩ 条，**限 ETF/LOF 作用域**）；消费端比率经 `ratio_or_default` 归一化（**≤0 ⇒ 不建模＋WARN，禁清零**——R54′）。tive` 排序。
- **分步耗时可选披露**：`bt run --verbose` 输出 `step_timings`（装配·前置/质检/组件 ‖ 运行·指纹/引擎/落盘）+ 数据质检与指纹摘要。

### 11.5 配置分层与示例

**四层合并（后者覆盖前者）**：① 内置默认（`btf/config/loader.py::DEFAULTS`）→ ② 环境变量（**仅 `BTF_*`**，白名单过滤）→ ③ 用户 YAML → ④ CLI `--set`（`a__b=v` 嵌套，类型推断单源在 `btf.app`）。

```yaml
schema_version: backtest.v1
run:
  strategy: tests.fixtures.buyhold:ConfigBuyHold     # module:Class（--resolve-strategy 可预检）
  params: {symbol: "600519.SH", weight: 0.9}
  universe: {source: explicit, symbols: ["600519.SH"]}
  period: {start: 2016-01-01, end: 2025-12-31}
  initial_cash: 10000000
data:
  feed: tushare_parquet
  feed_params: {root: "D:/全量数据/market_data"}
  fingerprint_mode: meta          # meta（缺省）| fast | full
  quality: {enabled: true, strict: false, max_symbols: 200}
execution:
  handler: next_open
  handler_params: {volume_participation: 0.05}   # VPP 5%（缺省；显式 null 或 {} = 不启用）
  cost_model: tiered_v1
  cost_model_params: {commission_rate: 0.00025}  # 成本模型构造参数（RC-05 已交付）
  slippage: {model: pct, params: {pct: 0.001}}   # 缺省：单边 10bp
  rebalancer: full
risk:
  rules: [{name: max_weight, params: {max_weight: 0.10}},
          {name: cash_check}, {name: tradability}]
  # allow_empty_chain: true  ← 仅调试用；缺省不声明 = 空链即拒绝运行
report:
  benchmark: "000300.SH"           # 配基准才计算超额/信息比率指标
  sections: [summary, equity, drawdown, monthly_heat, trades, assumptions, reproduce, appendix]
  # 「假设与披露」「复现说明」为强制章节，收窄 sections 也不会被移除
seed: {master: 20260926}
```

- **规则参数不得写数值**：经 `rules: {source: mirror_json, path: …}` 声明（[04 §8.3.7](04-领域模型与核心接口.md)）。
- **默认层现状**：`report.sections` 默认**全章**；`risk` 默认**不声明** `allow_empty_chain`（空链即 fail-closed）。
- **示例的时态（ADR-14）**：上例三项（`handler_params` / `slippage` / `cost_model_params`）**均已为现状**（RC-01/02/05 已交付）。
