# 采集进程管理操作说明

> 适用引擎：`alt.oversize_fetch`（外盘扩容多请求引擎）、`alt.list_backfill`（list 模式引擎）
> 操作对象：Windows 本机上的 Python 采集进程（`python3.13.exe` 或 `python.exe`）

---

## 1. 定位采集进程

PowerShell 一条命令列出所有 Python 进程及其命令行，**按命令行内容筛选出采集进程**：

```powershell
Get-CimInstance Win32_Process -Filter "Name='python3.13.exe'" |
  Select-Object ProcessId, CreationDate, CommandLine |
  Format-List
```

### 判据（命令行含以下任一关键词即采集进程）：

| 引擎 | 命令行特征 |
|---|---|
| `alt.oversize_fetch` | `-m alt.oversize_fetch --table hk_val_pct` |
| `alt.list_backfill` | `-m alt.list_backfill --table <表名>` |

### 批量只看采集进程：

```powershell
Get-CimInstance Win32_Process -Filter "Name='python3.13.exe'" |
  Where-Object { $_.CommandLine -match "alt\.(oversize_fetch|list_backfill)" } |
  Select-Object ProcessId, CreationDate, CommandLine
```

### 典型输出（审查方 P-0 实跑结果）：

```
ProcessId   CreationDate          CommandLine
---------   ------------          -----------
    12345   20261023220000.000000  python3.13.exe -m alt.oversize_fetch --table hk_val_pct
    23456   20261023220500.000000  python3.13.exe -m alt.list_backfill --table hk_daily
    34567   20261023221000.000000  python3.13.exe -m alt.list_backfill --table hk_qfq_factor
```

## 2. 停止方式

### 2a. 优雅停止（优先）

在采集进程的控制台窗口按 **Ctrl-C**。引擎内部有捕获逻辑：
- `oversize_fetch`：捕获后写入 checkpoint，已拉完的批次落盘不丢
- `list_backfill`：捕获后同样写 checkpoint + 记轮转水位

**何时用**：你能找到进程对应的控制台窗口时。

### 2b. 强制停止（无控制台或 Ctrl-C 无效）

```powershell
# 先确认这是采集进程（防误杀！）
Get-CimInstance Win32_Process -Filter "ProcessId=12345" | Select-Object ProcessId, CommandLine

# 再杀
Stop-Process -Id 12345 -Force
```

### 杀多个（全部采集进程）：

```powershell
Get-CimInstance Win32_Process -Filter "Name='python3.13.exe'" |
  Where-Object { $_.CommandLine -match "alt\.(oversize_fetch|list_backfill)" } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force; Write-Host "Stopped PID $($_.ProcessId)" }
```

**⚠ 注意**：强制停止时，当前正在 flush 的批次可能丢失（buffer 未落盘）。引擎设计已保证"先落盘、后记 checkpoint"，所以 checkpoint 里未记录的批次下次重拉会自然覆盖，不会造成不一致。

## 3. 三次采样确认（进程已完全停止）

停进程后**不能立即认为数据冻结**——需要三次采样验证采集目标目录静止。

### 采样方法：比较目录总字节数 + mtime + checkpoint 状态

```powershell
# === 基线时刻 t0 ===
$target = "D:\全量数据\alt_data\hk_val_pct"
$checkpoint = "D:\全量数据\alt_data\_meta\oversize_hk_val_pct_checkpoint.json"

function Get-DirSnapshot($path) {
    if (-not (Test-Path $path)) { return $null }
    $files = Get-ChildItem -Recurse -File $path -ErrorAction SilentlyContinue
    [PSCustomObject]@{
        Bytes  = ($files | Measure-Object -Property Length -Sum).Sum
        Count  = $files.Count
        Mtime  = ($files | Sort-Object LastWriteTime -Descending | Select-Object -First 1).LastWriteTime
    }
}

$s0 = Get-DirSnapshot $target
Write-Host "t0: bytes=$($s0.Bytes) count=$($s0.Count) mtime=$($s0.Mtime)"

# === 60 秒后 t1 ===
Start-Sleep -Seconds 60
$s1 = Get-DirSnapshot $target
Write-Host "t1: bytes=$($s1.Bytes) count=$($s1.Count) mtime=$($s1.Mtime)"

# === 再 60 秒后 t2 ===
Start-Sleep -Seconds 60
$s2 = Get-DirSnapshot $target
Write-Host "t2: bytes=$($s2.Bytes) count=$($s2.Count) mtime=$($s2.Mtime)"

# === 再 60 秒后 t3 ===
Start-Sleep -Seconds 60
$s3 = Get-DirSnapshot $target
Write-Host "t3: bytes=$($s3.Bytes) count=$($s3.Count) mtime=$($s3.Mtime)"
```

### 冻结判据（t0→t1→t2→t3 全部满足）：

| 指标 | 冻结条件 |
|---|---|
| 总字节数 | 三次 Δ = 0 |
| 文件数 | 三次 Δ = 0 |
| 最新 mtime | 三次不变 |
| checkpoint 文件 | 大小 + mtime 不变 |

### 审查方 P-0 实测（9 个 PID 全停后）：

```
Δ bytes = 0
Δ count = 0
Δ mtime = 0
checkpoint: 7,964B, done=505, fail=15, 零变化
→ 源端冻结 ✅（G1 门禁达成）
```

## 4. 断点续跑步骤

引擎自动支持——**停进程不丢进度**（只要不是在 flush 中途被强杀）。

### 4a. oversize_fetch 续跑：

```powershell
# 从 checkpoint 续拉（默认就是续拉模式，不加 --no-checkpoint 即可）
python -m alt.oversize_fetch --table hk_val_pct
```

内部逻辑：
1. 启动时读 `_meta/oversize_<table>_checkpoint.json`
2. 过滤出 `done=true` 的标的，跳过
3. 只拉未完成的标的
4. 每 flush 成功后更新 checkpoint

### 4b. list_backfill 续跑：

```powershell
# 轮转模式续跑（默认模式，自动选最旧的批次）
python -m alt.list_backfill --table hk_daily
```

内部逻辑：
1. 读轮转水位表
2. 算出最旧批次（rotate_days 到期的）
3. 只拉那一批

### 4c. 强制从头跑：

```powershell
# oversize_fetch：清 checkpoint
python -m alt.oversize_fetch --table hk_val_pct --no-checkpoint

# list_backfill：整表重建（影子目录安全替换）
python -m alt.list_backfill --table hk_daily --rebuild --yes
```

## 5. 避免误杀（关键：本机同时有 10+ Python 进程）

本机 Python 进程通常包含：VSCode Python 扩展、Jupyter kernel、pip install、测试脚本、临时 IDE 辅助进程等。**杀进程前必须先过滤后确认**。

### 安全杀进程 SOP：

```
Step 1: 列出所有 python 进程 → P1
Step 2: 用 Where-Object 过滤命令行 → P2（只有采集进程）
Step 3: 对 P2 里每个 PID，单独 Get-CimInstance 确认 → P3
Step 4: 逐个杀 P3
```

### 误杀后果：

| 误杀对象 | 后果 | 恢复 |
|---|---|---|
| VSCode Python 扩展 | 编辑器语法高亮失效 | VSCode 自动重启，无需手动 |
| Jupyter kernel | Notebook 执行中断 | `Kernel → Restart Kernel` |
| pip install | 当前安装的包残留半成品 | `pip install --force-reinstall <包>` |
| 其他数据采集（如 `wind_sync`） | 该引擎的数据流中断 | 手动重启该引擎 |

### 绝对不能杀的：

- PID 0 / 4 / System / registry 等系统进程
- 命令行含 `code`（VSCode）、`jupyter`（Jupyter）、`pip install`（安装）、`pytest`（测试）的
- 命令行**不含** `alt.oversize_fetch` 或 `alt.list_backfill` 的

## 附录：审查方 P-0 实操速查

```powershell
# --- Step 1: 列出所有采集 PID ---
$pids = Get-CimInstance Win32_Process -Filter "Name='python3.13.exe'" |
  Where-Object { $_.CommandLine -match "alt\.(oversize_fetch|list_backfill)" } |
  Select-Object ProcessId, CommandLine

# --- Step 2: 逐一确认 ---
$pids | ForEach-Object { Write-Host "PID $($_.ProcessId): $($_.CommandLine)" }

# --- Step 3: 全部停 ---
$pids | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }

# --- Step 4: 三次采样（60s 间隔，总时长 3 分钟）---
$target = "D:\全量数据\alt_data\hk_val_pct"
0..3 | ForEach-Object {
    Start-Sleep -Seconds 60
    $s = Get-DirSnapshot $target
    Write-Host "t$_ : bytes=$($s.Bytes) mtime=$($s.Mtime)"
}

# --- Step 5: checkpoint 也确认 ---
Get-Content "D:\全量数据\alt_data\_meta\oversize_hk_val_pct_checkpoint.json" | Select-Object -First 5
# done/fail 计数应不再增长
```
