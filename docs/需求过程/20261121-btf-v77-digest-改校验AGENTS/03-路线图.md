### 3.3 digest 口径

```
raw = path.read_bytes()
normalized = raw.replace(b"\r\n", b"\n")
digest = "sha256:" + hashlib.sha256(normalized).hexdigest()
size_bytes = len(raw)
line_count = len(normalized.splitlines())
```

主判定只比较 `digest`；`size_bytes` / `line_count` 写入输出与 `--out`，便于人工核对。

### 3.4 基线 JSON schema

```json
{
  "schema": "agents-digest-baseline/v1",
  "target": "赤潮/AGENTS.md",
  "frozen_at": "2026-11-21T12:00:00+08:00",
  "reason": "初始冻结：赤潮 v7.8 单一规则源 AGENTS.md（REQ-20261121-01）",
  "sha256": "sha256:52cf3305415d7c508d8545688fd9b6fcfbd64c503195d3bd4ccffce978490ddc",
  "size_bytes": 87836,
  "line_count": 522,
  "previous": []
}
```

- `target` 仅人类可读，不参与判定。
- `--update`：`reason` 为空 → exit 2；旧基线可解析时把 `{sha256, frozen_at, reason}` 追加到 `previous` 尾部；旧基线损坏 → exit 2（不得静默覆盖）。
- 初始冻结的 `sha256` 以 `--update` 实测值为准；上式值为 2026-11-21 事实锚点，供编码会话核对。

### 3.5 CLI 与退出码

```
python tools/check_v77_digest.py [--baseline PATH] [--out JSON] [--update --reason TEXT]
```

- `--baseline` 默认 `tools/agents_digest_baseline.json`。
- `--out`：写实测 JSON（`schema=agents-digest-check/v1`，含 `source` / `digest` / `size_bytes` / `line_count` / `baseline` / `baseline_digest` / `ok` / `checked_at`）。
- 退出码：`0`＝一致；`1`＝不一致；`2`＝源/基线不可读、schema 非法、`--update` 缺 `reason`。
- `--help` 中不得出现 `--tiers` / `--runs-dir` / `--smoke`。

### 3.6 输出规范（供测试断言）

统一使用 ASCII 标签＋中文说明；保留 `_harden_stdout()`（N45 纪律：管道捕获时不可编码字符降级）。

| 场景 | stdout/stderr | 退出码 |
|---|---|---|
| 一致 | `[ok] source = <path>` / `[ok] size = 87836 B \| lines = 522` / `digest = sha256:<...>` / `baseline = sha256:<...>` / `[ok] AGENTS.md digest 校验通过` | 0 |
| 不一致 | `[mismatch] source = <path>` / `digest = ...` / `baseline = ...` / `[mismatch] AGENTS.md digest 不匹配（如属规则变更，请 --update --reason 重冻结）` | 1 |

| `--update` 缺 reason | stderr：`[error] --update 必须带 --reason` | 2 |
| `--update` 成功 | `[ok] baseline updated: <old> -> <new>`（首次为 `(new) -> <sha>`） | 0 |
