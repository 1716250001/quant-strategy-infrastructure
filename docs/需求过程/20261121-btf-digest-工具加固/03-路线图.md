## 二、路线裁定

| 问题 | 裁定 | 判据 |
|---|---|---|
| F1 互斥方式 | **解析后显式拒绝**：`--update` ＋ `--out` → stderr `[error]`、exit 2；不用 `argparse` 互斥组 | 保持全工具统一的 `[error]` 文案与 exit 2；互斥组会输出 argparse 的 usage（英文、格式不一），测试与运维口径不一致 |
| F2 严格度 | **必填字段＋类型＋格式全查**：`target/frozen_at/reason` 非空 str；`sha256` 匹配 `^sha256:[0-9a-f]{64}$`；`size_bytes/line_count` 为正整数；`previous` 为 list 且条目 `sha256` 合法 | 这些字段是审计/复现的最小集；只查前缀会让 `sha256:xyz` 进入比对并产生「永远 mismatch」的假红；严格校验不影响现有基线（字段齐全） |
| F3 原子写 | **同目录临时文件 ＋ `os.replace` ＋ `finally` 清理**；`_write_json` 统一用于基线与 `--out` | `os.replace` 在同卷原子替换；临时文件同目录保证不跨卷；`finally` 清掉失败残留，避免 `.tmp` 堆积 |
| 测试覆盖 | **继续扩展现有单函数**，追加子例 7–9；**不新增测试函数** | 保持 collect 1,306；子例标签可精确定位；与新需求 REQ-02 的计数约束一致 |

## 三、目标行为规格

### 3.1 F1：`--update` / `--out` 互斥

在 `args = ap.parse_args(argv)` 之后、`if args.update and not args.reason.strip()` 之前加：

```python
if args.update and args.out:
    print("[error] --out 仅用于校验模式，不能与 --update 同用",
          file=sys.stderr)
    return 2
```

`--out` 在 `--update` 模式下不再有任何写入；`--update` 的成功输出保持 `[ok] baseline updated: ...`。

### 3.2 F2：基线 schema 严格校验

在 `load_baseline` 中引入模块级正则（`import re`）：

```python
_SHA256_RE = re.compile(r"^sha256:[0-9a-f]{64}$")
```

校验改为（保持统一抛 `BaselineError(str(path))`）：

```python
def _is_pos_int(v: object) -> bool:
    return isinstance(v, int) and not isinstance(v, bool) and v > 0


def load_baseline(path: Path) -> dict:
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError) as exc:
        raise BaselineError(str(path)) from exc
    if (not isinstance(data, dict)
            or data.get("schema") != BASELINE_SCHEMA
            or not isinstance(data.get("target"), str) or not data["target"]
            or not isinstance(data.get("frozen_at"), str) or not data["frozen_at"]
            or not isinstance(data.get("reason"), str) or not data["reason"]
            or not isinstance(data.get("sha256"), str)
            or not _SHA256_RE.match(data["sha256"])
            or not _is_pos_int(data.get("size_bytes"))
            or not _is_pos_int(data.get("line_count"))
            or not isinstance(data.get("previous"), list)):
        raise BaselineError(str(path))
    for entry in data["previous"]:
        if (not isinstance(entry, dict)
                or not _SHA256_RE.match(str(entry.get("sha256", "")))
                or not isinstance(entry.get("frozen_at"), str)
                or not isinstance(entry.get("reason"), str)):
            raise BaselineError(str(path))
    return data
```

- 现有正式基线字段齐全，校验通过。
- 自定义旧基线若缺字段，将按预期 exit 2；属**有意的收紧**，在 09 §14.4.2 注明。

### 3.3 F3：原子写入

`_write_json` 改为：

```python
def _write_json(path: Path, payload: dict) -> None:
    tmp = path.with_name(path.name + ".tmp")
    try:
        tmp.write_text(json.dumps(payload, ensure_ascii=False, indent=2) + "\n",
                       encoding="utf-8")
        os.replace(tmp, path)
    finally:
        if tmp.exists():
            try:
                tmp.unlink()
            except OSError:
                pass
```

- 基线与 `--out` 共用；正常路径输出内容与现实现逐字节一致。
- 失败时正式文件保持原状（不会半截覆盖）；`.tmp` 在 `finally` 清理。
- 备注：若 `--out` 的父目录不存在，`tmp.write_text` 抛 `OSError`，由现有 `except OSError` 分支报 `[error] 实测 JSON 写入失败` 并 exit 2（行为不变）。
